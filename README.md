# Modern Web Calculator 🧮

A modern, fully responsive, and feature-rich Calculator application built with HTML, CSS, and vanilla JavaScript. This project was developed as a frontend practice project to demonstrate clean UI/UX design, interactive key events, and dynamic logic implementation.

---

## ✨ Key Features

* 🔢 **Standard Arithmetic Operations:** Supports addition, subtraction, multiplication, and division with real-time result calculation.
* ⌨️ **Keyboard Support:** Full compatibility with physical keyboard inputs, including numbers, operators, Enter (for result), and Backspace (for deletion).
* 📱 **Responsive Design:** A mobile-first design approach using CSS Grid and media queries to ensure the calculator looks perfect on desktops, tablets, and mobile devices.
* 🎨 **Advanced UI/UX:** Features smooth "pop" animations on results, pulse animations, and a modern dark-mode aesthetic with glassmorphism-inspired components.
* 🛡️ **Robust Logic:** Includes error handling for invalid math expressions and automatic formatting for long numbers.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure with modular button definitions.
* **CSS3:** Advanced styling utilizing Flexbox, CSS Grid, keyframe animations, and custom scrollbars.
* **JavaScript (Vanilla):** Dynamic DOM manipulation, event listeners for mouse/keyboard inputs, and robust math evaluation logic.
